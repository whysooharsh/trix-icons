# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in `trix-icons`, please do not open a public issue.

Report security issues privately to the project maintainers. Include:

1. Description of the vulnerability and potential impact.
2. Steps or minimal reproduction script to demonstrate the issue.
3. Affected package(s) and version(s).

## Supported Versions

| Package | Version | Supported |
| --- | --- | --- |
| `trix-icons` (CLI) | `0.1.x` | Yes |
| `@trix/icons` | `0.1.x` | Yes |
| `@trix/core` | `0.1.x` | Yes |
| `@trix/registry` | `0.1.x` | Yes |

## Disclosure & Remediation Policy

Maintainers will review reported vulnerabilities within 48 hours, confirm impact, and coordinate a patch release.
